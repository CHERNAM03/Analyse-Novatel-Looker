# 📊 Analyse et Tableau de bord - Réservations d'Hôtels

Ce projet présente l'analyse complète de données hôtelières, de l'extraction des données via des requêtes SQL jusqu'à la visualisation sur un tableau de bord.

## 🛠️ Stack Technique
- **Base de données / Entrepôt :** Google BigQuery
- **Automatisation & Extraction :** BigQuery Connector
- **Visualisation :** Looker Studio

## 📂 Contenu du dossier
- `Novatel_requetes.sql` : Les requêtes SQL écrites en syntaxe Standard SQL pour BigQuery.
- `dashboard.png` : Aperçu visuel du tableau de bord.
